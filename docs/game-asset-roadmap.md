# Game asset extension roadmap

Canonical JSON traces are integrated with manifest validation, capability planning, reports, and coverage. The analyzer accepts versioned Godot 4 and Unity export wrappers around the same canonical trace; analysis itself never opens engine project files or runs project scripts. Separate commands offer bounded read-only source-project discovery and an explicit engine exporter path; see [project discovery](project-discovery.md).

Trace evidence includes frame sequences, position/rotation/pose tracks, events, contact intervals, anchor pairs, particles, and PNG frame layers. Samples declare timebase, frame/timestamp, coordinate space, units, interpolation, and random seed where relevant.

Implemented checks include position, velocity, acceleration, jerk, quaternion rotation distance, pose and loop boundaries, event timing, anchor distance, bone-length deviation, foot sliding, particle lifetime and AABB bounds, and alpha-weighted occlusion. Layer records can select `[x, y, width, height]` regions from sprite atlases. Local positions compose through synchronized parent tracks with per-sample 2D/3D basis matrices, including changing rotation and scale. Paths stay within the trace directory. Missing or incompatible evidence yields `INCONCLUSIVE`.

Godot 4.6.3 and Unity 6000.3.25f1 exporters were exercised through the checked-in fixtures; each emitted a versioned static trace that the CLI then analyzed. A separate `i_mage_not_ai.runtime-evidence/1` contract now records observed callbacks and live particle state, with a deterministic policy checker. Godot Forward+ and Unity Play Mode fixture observations passed. Runtime evidence remains outside the static trace contract. Project discovery only parses bounded text metadata and selected static references; it cannot resolve dynamic loading or every native asset format. Arbitrary projects need an instrumented adapter and an explicit scenario. The CLI keeps plugin loading disabled; embedding hosts can use the documented API only for explicitly reviewed code.
